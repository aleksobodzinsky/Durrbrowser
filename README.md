# Durrbrowser

My own browser on PyQT5, written in Python. This browser includes a Chrome 129 engine and enabled JavaScript by default. This means websites ACTUALLY work, well sometimes it crashes, but then it's fine, i dont know tho. Basically an usable browser from scratch. :PPPP

## Requirements

- `PyQt5>=5.15.0`
- `PyQtWebEngine>=5.15.0`

## 📖 Author's Notes

### Why another browser?
Because i wanted to. And because every time i open Chrome, my old laptop’s fan screams so loud i can’t hear my own thoughts. So i made a browser that doesn't eat 8GB of RAM for breakfast. :P

### Does it have tabs?
Not yet. I like my windows like my commit history — clean and simple. But tabs are planned. Maybe.

### Why "Durrbrowser"?
Well, my other project is a programming language called **Durrlang** (yeah, i have one, it's an esolang). So the naming scheme just kinda... happened.

### Who are you?
Just a guy from Russia who likes to make things work on hardware that people gave up on. Mac mini 2012, Arduino Uno, old iPhones. If it's obsolete, i try to make it useful again. That's the vibe.
